PROJECT BARU — UNDANGAN GIAN & RAIGA

1. Upload SELURUH isi folder ini ke repository GitHub BARU.
2. Pastikan index.html berada di root repository (halaman utama), sejajar dengan folder images dan music.
3. Masukkan file MP3 ke folder music dan beri nama music-undangan.mp3.
4. Di GitHub buka Settings > Pages > Deploy from a branch > main > /(root) > Save.
5. Tunggu proses Pages selesai, lalu buka URL GitHub Pages yang ditampilkan.
